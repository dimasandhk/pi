# Scientific integrity and final quality gates

## Gate 1: Method audit
- [ ] Exact databases/platforms actually searched.
- [ ] Exact date of each run and effective search coverage.
- [ ] Full per-database queries, limits, exports and deviations retained.
- [ ] Record/report/study counts reconcile across logs, PRISMA, tables and abstract.
- [ ] Dedup rules and multi-report empirical studies treated consistently.
- [ ] Eligibility decisions have documented human/automation provenance.
- [ ] Reviewer number, independence, pilot and conflict-resolution actions backed by decision logs.
- [ ] Full-text retrieval status and reasons for exclusion backed by actual documents.
- [ ] QA instrument, threshold, score explanations, reviewer confirmation and actual use in selection specified.
- [ ] Snowballing/completeness described as actual or pending; never silently assumed complete.

## Gate 2: Evidence trace
- [ ] Every material empirical sentence links to exact primary-study IDs and reported measures.
- [ ] No source invented; DOI/title/authors/year match.
- [ ] Claims not stronger than design supports (especially causal verbs).
- [ ] Direct comprehension vs proxy vs productivity consistently separated.
- [ ] Contradictory and null findings deliberately included.
- [ ] No unqualified 'all', 'significant', 'proves', 'novel', or 'first'.

## Gate 3: Results and synthesis
- [ ] All RQs explicitly answered, at the scope supported by the studies.
- [ ] Each RQ uses an evidence synthesis table/matrix, not one-study-at-a-time chronology.
- [ ] Denominator for each percentage/count is stated.
- [ ] Studies with multiple reports/arms are not double counted.
- [ ] Qualitative codes/themes have linked excerpts or page-level evidence.
- [ ] Groupings/methods justified; heterogeneity and sensitivity explored if meaningful.
- [ ] Distinguish study QA from overall certainty/confidence in a synthesized result.

## Gate 4: Reporting conformance
- [ ] SEGRESS items checked for applicability, with status and rationale for omissions.
- [ ] PRISMA 2020 stage counts, flow and reporting items checked.
- [ ] PRISMA-S search reproducibility checked.
- [ ] SWiM checked only if quantitative intervention effects summarized without meta-analysis.
- [ ] Review-process limitations distinguished from included-primary-study limitations.
- [ ] Protocol registration, funding, conflicts, data/material availability addressed accurately.
- [ ] Main text concise; appendices contain reproducibility assets, not hidden essential results.

## Gate 5: Manuscript quality
- [ ] Introduction goes from broader problem to narrow, substantiated gap.
- [ ] Prior SLR comparison is fair and specific.
- [ ] Title + structured abstract accurately reflect final evidence.
- [ ] Figures/tables are consistently labeled, cited, readable and self-explanatory.
- [ ] References and in-text citations use target venue/course style.
- [ ] Claims and conclusions remain correct if read without Discussion.
- [ ] Every [TO VERIFY] has either been resolved or explicitly retained as a limitation; never quietly deleted.

## Status policy
Return `BLOCKED`, `DRAFTABLE`, or `FINAL-READY` for each section.
- `BLOCKED`: missing data or documented method needed to support the proposed claim.
- `DRAFTABLE`: background/method skeleton and transparent preliminary results possible.
- `FINAL-READY`: source-grounded findings, reviewer provenance, and applicable checks are complete.
Report actionable fixes, not generic comments.
